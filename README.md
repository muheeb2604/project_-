# AI SaaS Dashboard

A static frontend prototype for a premium AI SaaS dashboard experience, covering:

- Landing page
- Login / signup flow
- Dashboard analytics and notifications
- AI chat workspace
- Settings panel
- Dark / light theme toggle

## Files

- `index.html` — overall page structure and content
- `styles.css` — premium dashboard styling and responsive layout
- `script.js` — light/dark theme toggle and auth modal behavior

## Run locally

Open `index.html` directly in a browser.

If you want a local web server, you can run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000
